# 01 — Setup

Install the tooling to follow all labs in the workshop. This file links to the official setup instructions only — follow each project's own docs for your OS.

Everything else in the workshop runs on **Corellium** (access instructions provided later), so jadx is the only tool you need on your own machine.

> Want your own **local rooted Android device** to practice at home? Follow the optional, self-contained guide in [`02-Android-Studio-Setup.md`](./02-Android-Studio-Setup.md).
