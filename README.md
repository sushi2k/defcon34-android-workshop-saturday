# DEF CON Workshop: Practical Android App Security Testing with OWASP MAS

**Speaker:** Sven Schleier

**Session type:** Workshop

**Duration:** 90 minutes

## Abstract

Mobile app testing has many pitfalls, and a structured approach is needed to get a holistic picture of the attack surface. The [OWASP Mobile Application Security (MAS)](https://mas.owasp.org/) project supports you with exactly that. This hands-on workshop gives a practical
introduction to the MAS ecosystem — the standard, the mobile weaknesses, and how to test them. You'll run test cases and demos for Android in action, covering static analysis, and learn how to perform a mobile penetration test.

## Learning Objectives

By the end of the workshop, attendees will be able to:

- Navigate the OWASP MAS project (MASVS, MASWE, MASTG) and locate relevant test cases for their own engagements.
- Apply a mix of static and dynamic analysis techniques against real Android apps.
